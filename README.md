# Relief Time Restaurant

A responsive, single-page restaurant website built with plain HTML, CSS, and JavaScript. It has no build step or package dependencies and can be hosted directly with GitHub Pages.

## Preview locally

Open `index.html` in a browser, or use the VS Code Live Preview/Live Server extension.

## Publish with GitHub Pages

1. Push this repository to GitHub with `index.html` at the repository root and the `main` branch.
2. In the repository, open **Settings > Pages**.
3. Under **Build and deployment**, choose **GitHub Actions** as the source.
4. The included workflow deploys the site after each push to `main`. GitHub will show the published URL in the Pages settings when its first deployment finishes.

## Before publishing

Update the sample business details in `index.html` to the restaurant's real information: phone and WhatsApp number, email address, location, opening hours, and social profile URLs. The booking and contact forms use WhatsApp and the visitor's email application; they do not store submissions or send messages automatically. A backend or form service is needed for automatic handling.

Menu items, prices, and business claims should also be checked for accuracy before launch.
